# Xtet — CTET Paper-I Hub

CTET Paper-I (Classes I–V) ke liye ek organized hub:

- **`sessions/`** — 2020 ke baad ki har CTET session ka metadata (date, edition, mode, shifts,
  official answer-key info) + official sources ke links. Real question papers CBSE ki website se
  download kiye ja sakte hain — links har session ke folder mein hain.
- **`practice/`** — CTET Paper-I ke exact pattern par likhe gaye **original practice sets**
  (150 questions, bilingual Hindi+English, section-wise JSON, answer key ke saath) — app-ready format.

## CTET Paper-I Pattern

| Section | Questions | Numbering |
|---|---|---|
| I. Child Development and Pedagogy (बाल विकास एवं शिक्षण शास्त्र) | 30 | 1–30 |
| II. Language I (भाषा-1 — Hindi/English/Sanskrit, candidate's choice) | 30 | 31–60 |
| III. Language II (भाषा-2 — different language, candidate's choice) | 30 | 61–90 |
| IV. Mathematics (गणित) | 30 | 91–120 |
| V. Environmental Studies (पर्यावरण अध्ययन) | 30 | 121–150 |

- Total: **150 questions, 150 marks, 150 minutes**, no negative marking.
- Actual booklet mein Language sections ke andar 20+ languages ke blocks hote hain; candidate
  apni Language-I aur Language-II ke blocks answer karta hai.

## Important disclaimer

Is repo mein **CBSE ke actual question papers copy nahin kiye gaye hain** — CTET ke question
papers aur answer keys CBSE ka copyrighted material hain. Har session ke folder mein official
sources ke links diye gaye hain jahan se original PDFs legally download kar sakte ho.
`practice/` mein jo sets hain wo **original, naye likhe gaye questions** hain jo CTET ke syllabus
aur pattern par based hain.
