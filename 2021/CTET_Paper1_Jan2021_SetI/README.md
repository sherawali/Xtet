# CTET Paper 1 - January 2021 - Set I

Is folder mein 31 January 2021 ko hue CTET Paper 1, Set I ke questions aur CBSE ki official final answer key di gayi hai.

- Exam: CTET - Central Teacher Eligibility Test
- Exam cycle: CTET 2020 (exam held in 2021)
- Paper: Paper 1 (Primary Level, Classes I to V)
- Exam date: 31 January 2021
- Paper set: Set I
- Booklet code: AAT-20-I
- Total questions: 150
- Duration: 2.5 hours
- Negative marking: Nahi

## Notes

- The booklet places English before Hindi within each language part. The four language sections are separate options; each file contains one language only. CBSE's instructions require the Language II choice to differ from the Language I choice.
- English and Hindi language-section questions are not treated as translation pairs; each section is transcribed and keyed independently from its own booklet stream.
- The official booklet's Hindi text layer is legacy-font encoded. The clean Hindi transcription was cross-checked against Studyfry; therefore, exact Hindi typography/wording is not independently verified against a clean official scan. Question sequence and option order follow the official booklet.
- Studyfry's suggested answers are not used as the answer authority. The key follows CBSE's official final key. Noted third-party discrepancies: EVS Q90 (official option 3, South America; Studyfry lists option 4), English Language II Q145 (official option 3, multilingualism; Studyfry lists option 2), and Hindi Language I Q106 (official option 2; Studyfry lists option 1).
- No Sanskrit or other language supplements are included in this Set I booklet folder; only the four language sections listed above are transcribed here.
