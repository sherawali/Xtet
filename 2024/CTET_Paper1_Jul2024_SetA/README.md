## Notes

- CDP, Maths aur EVS booklet mein Hindi + English dono bhashaon mein chhape hain - isliye un files mein har question English block + Hindi block ke saath diya gaya hai. Language sections single-language format mein hain (jaisa booklet mein hai).
- Set A ke booklet mein chaar language sections hain: Part IV English (Q91-120), Part IV Hindi (Q91-120), Part V English (Q121-150), Part V Hindi (Q121-150). Ek candidate apne chune hue Language I/II hi attempt karta hai (Part IV me ek, Part V me doosri bhasha). Isliye chaaron sections yahan diye gaye hain.
- Part IV/V ke aakhri 15-15 pedagogy questions (Q106-120, Q136-150) dono bhashaon ke section mein same numbering par hain aur unke official answers bhi identical hain.
- Hindi text is booklet ke mirror mein legacy Chanakya-font encoding mein hai. Hindi sections yahin se decode karke likhe gaye hain, aur wording/option-order ka cross-check adda247 ki clean Hindi solution PDF se kiya gaya hai. Har question ka answer CBSE ki official final key se verified hai.
- Question text ka main source: July 2024 Paper 1 Set A ka poora text-layer booklet (48 print pages, code JSS-24-I) prepp CDN par: https://cdn-images.prepp.in/public/image/JSS_24_I_Paper_I_Eng_Hin_AAAA_df9531e82c9d92ed0b91bc08c0d69085.pdf (r.jina.ai se padha gaya)
- Answer-Key.txt CBSE ki official Final Answer Key (29/07/2024 jari) se banayi gayi hai. Official key mein har set ke liye do tables hain - Set A ke liye `01-ENGLISH` (page 5) aur `02-HINDI` (page 9) - dono tables yahan use kiye gaye hain.

## Official Key Notation

- Numbers (1-4) = wahi option number jaisa question paper mein chhapa hai.
- Multiple/combined answers: A = options 1 aur 2, B = options 1 aur 3, C = options 1 aur 4, D = options 2 aur 3, E = options 2 aur 4, F = options 3 aur 4, Z = saare options.
- Is Set A mein: Maths Q35 = Z, Q48 = Z; EVS Q63 = D, Q90 = A; Language (English aur Hindi dono) Q136 = B.
